# 홈페이지 네 언어 대응

2026-10-12 사용자 요청. 기존 한국어에 일본어·대만 번체·영어를 추가하고 그 외 언어는 지원하지 않는다. Bandlog 앱과 동일한 스토어 이미지의 언어권을 사용한다.

## 동작 기준

1. 저장한 수동 선택을 우선한다. 저장한 값이 없거나 잘못되면 기기의 선호 언어를 순서대로 확인한다. 지원 언어를 찾지 못하면 영어를 쓴다.
2. 한국어·일본어·영어의 지역 변형과 번체 중국어의 script/지역을 인식한다. 간체 중국어는 별도 지원하지 않는다.
3. 상단 native select에 각 언어의 자기 이름을 표시한다. 선택은 브라우저 `localStorage`에 보관하며 저장 접근이 막힌 경우에도 현재 방문에서는 선택할 수 있다.
4. 본문·페이지 제목·메타 정보·접근성 문구·이미지 5장과 캡션을 함께 바꾼다. 확대 갤러리도 현재 언어의 이미지와 문구를 쓴다.
5. JavaScript가 없어도 영어 본문과 이미지를 볼 수 있다. 기존 정책 링크와 법정 회사 정보는 보존한다.
6. 한국어 이미지는 기존 승인본을 유지하고 외국어 이미지는 Bandlog PR #1075의 Figma Ready localized-r1 원본에서 파생한다.

## 검증

- `node --test test/localization.test.mjs`: 언어 정규화, 저장 선택 우선순위, 영어 fallback, 네 언어 리소스 누락 검사 3개 통과.
- 브라우저 375px·1440px에서 네 언어의 선택과 새로고침 유지, 모든 이미지 로딩과 문구, 가로 넘침 없음을 확인했다.
- 320px 일본어 제목의 grid 최소 폭과 글자 크기를 보정하고 320px에서 가로 넘침 없음을 재확인했다.
- 영어 확대 갤러리의 원본 연결·다음 이미지·Escape 닫기, console error 0건 확인.
- `git diff --check` 통과. 공개 배포 후 Pages 결과와 live HTML/CSS/module/이미지 체크섬을 따로 확인한다.
